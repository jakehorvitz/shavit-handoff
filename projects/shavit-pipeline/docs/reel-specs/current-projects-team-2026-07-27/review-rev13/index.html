The film

How Oak runs now

  1. Ladder room owns the whole screen, then settles into the top-left — and as it shrinks, the green room is already there full-screen behind it.
  2. Green room owns the screen, then settles into the top-right, exposing the arch.
  3. Arch to the front door owns the screen, then settles into the bottom-left, exposing the kitchen.
  4. Kitchen owns the screen last — it is the strongest photo, so it gets the final full-screen beat — then settles into the bottom-right, where the eye finishes.
  5. All four hold, each still running its own slow pan, until the white flash into Indiana.
Why this reads as natural instead of as an effect. Two things, and both fall out of the geometry rather than being animated in.

1. It is a pure uniform scale. The frame is 9:16 and every corner cell is 9:16, so a photo travelling from full screen to a corner is just the same image getting smaller. Nothing warps, nothing re-crops, no aspect snaps at the end. That is what makes it read as a physical object receding rather than a transition playing.

2. Nothing ever enters. The four photos start stacked full-screen, front to back. Each one shrinks away and exposes the next already sitting there. No slide-in, no fade-up, and not one frame of empty background anywhere in the clip — the space a shrinking photo vacates is always either a corner that is already filled or the next photo underneath.

Easing is ease-in-out cubic: starts at rest, ends at rest, no overshoot. A bounce would have read as a cartoon, which is the opposite of what you asked for.

Read before you sign off

A bug this pass nearly shipped. The first export of this version went black for the last half-second of Oak. Palmier caches an imported asset's frame count, and I had overwritten the clip file in place while making it longer — so the timeline asked for frames the editor still believed did not exist. Caught it in the rendered pixels, not in the timeline. The fix is that the clip filename is now versioned, and the renderer carries a comment saying why.
The one real cost. Four equal cells in a 9:16 frame forces each cell to 9:16 too, so each 3:4 photo gives up 25% of its width when it is in a corner. Nothing important is lost — the ladder room keeps both windows, the kitchen keeps the base cabinets, sink and faucet, the arch shot keeps the arch and drops a folding chair — and the full-screen beat before each settle shows the same crop, so you always see the photo at full size before it shrinks.
Still open, unchanged. Howder's clipped carpenter is the oldest defect in the film, 7.5 credits against roughly 20 available. Ludlam now opens the film on its single usable photo, and that frame shows gas meters on the side elevation — worth asking Shavit for a front elevation.
