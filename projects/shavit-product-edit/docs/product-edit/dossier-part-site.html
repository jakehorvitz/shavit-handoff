What phones still allow

JS-written transform, opacity, clip-path; class toggles; position:sticky; native muted inline video. Not allowed: CSS time-based animation, blur/filter, blend modes, will-change. Two lanes for a new effect: desktop-only behind min-width:768px (needs no iOS testing), or a proven-safe opt-out like the intro (needs on-device proof).
