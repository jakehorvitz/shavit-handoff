7 · Scope, anti-requirements, and failure handling

In scope

  • One 1080×1920, 30fps, 1885-frame master timeline.
  • Four approved single-move generated candidates maximum.
  • Native photo fallbacks for every generated candidate.
  • Palmier source project remains the active August reels project.
  • One caption draft; Jake/Shavit publish.

Hard no

  • No fabricated architecture, outpaint, or missing-angle reconstruction without Shavit’s written OK. Your Norwood extension ask is the one exception on the table, and it is gated.
  • No multi-axis “cinematic” camera choreography; one move per shot.
  • No corner turns or interior orbits.
  • No generated text, logos, construction progress, cars, weather, or object motion. No generated people without Shavit’s written OK; real crew footage first (E Ewing).
  • No public addresses, prices, tenant details, or unsupported outcomes.

Fallback ladder

  1. First generated take passes plate-lock review.
  2. If not, one tightened prompt/retry only after approval.
  3. If still unstable, use native still with Palmier crop/scale.
  4. If Ludlam provenance stays ambiguous, use typography-only.

Known risks

  • Barry’s September 7 target can age; re-confirm before publish.
  • Ludlam’s lone attachment is not yet property-confirmed.
  • Palmier generation is currently disabled.
  • AI motion may deform openings or reveal invented space; any such frame rejects the take.
  • Two beats (Norwood extension, Ewing workers) depend on Shavit saying yes to invented pixels. Ask before generating; both have native fallbacks.
