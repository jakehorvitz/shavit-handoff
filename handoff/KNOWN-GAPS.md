- **Coverage:** this is the recovered local Shavit archive plus curated cross-session history, not a claim that every remote Drive asset or every historical message attachment has been downloaded. See the file/source and missing-media catalogs for exact coverage.
- **Facts registry:** `projects/shavit-pipeline/facts/` did not exist locally. Existing `FACTS-TO-ADD.md`, queues and claims are proposals/evidence, not verified facts. Restore it with actual human confirmation.
- **August recap:** September 6 Palmier edits are newer than some numbered exports. Confirm the final exported and posted version.
- **Longform:** the July review names `deliver/master_9x16.mp4`, `export_16x9.mp4` and `export_4x5.mp4`, but those master files were not present in the source folder. Other longform variants, the vertical remaster, captions, posters and staging previews were recovered.
- **Mead cover:** the selected cover has recorded generated-rendering provenance and a disclosure requirement. Keep that provenance with it, or select the real-photo alternative.
- **Dependencies:** clean installation reported 8 existing dependency audit advisories (4 moderate, 4 high). The handoff preserves the lockfile; dependency upgrades were not made as part of archiving. Build also emitted the existing React `buffer` attribute warning.
- **Website tests:** the previous September 7 task recorded a passing production build and 10 legacy acceptance-script failures. Those old assertions are not a clean baseline for today's source. Archive verification is reported separately in `catalog/VERIFICATION.md`.
- **Historical conflicts:** early docs describe forms/lead databases, AI/Street View visuals, automatic posting after a veto window and faster posting cadence. Later source favors SMS-only contact, real property imagery, explicit content approval and a 2–3/week ceiling. Historical files remain for context, not as current operating instructions.
- **Historical comparison links:** four July review-page “previous version” symlinks point to absent old exports. Their original targets are recorded in `catalog/missing-comparison-links.json`; the recovered actual revisions remain archived.
- **External media/fonts/tools:** original render scripts contain machine-specific paths. Restore the release, use the Palmier relink helper, and update an archive copy's paths for your machine. Never assume that a project package alone includes all original footage.
- **Deliberate omissions:** credentials, `.env` files, original Git databases, dependency caches, raw agent logs, partial downloads, raw private conversations, personal career/negotiation notes and known private desktop captures are excluded. Some render scripts that depended on those omitted captures will require the cleaned replacement plates.
- **Source location:** substantial originals were on iCloud Desktop/Documents. This handoff is under `~/projects` so its active source is outside those locations. Original files were left untouched.
- **Publication and rights:** “FINAL,” a checked-in approval artifact, or a draft render does not prove it was posted or authorize a new publication. Music/reference footage and fonts retain their source rights. Keep the archive private and resolve use permissions before reusing restricted references.
